# Features

Mỗi feature chứa page, component, hook và schema biểu mẫu riêng. Các nhóm dự kiến:
dashboard, auth, transactions, wallets, categories, budgets, recurring, savings,
reports, search, receipts, settings, notifications và admin.

Chỉ tạo file triển khai khi bắt đầu feature tương ứng; không dùng dữ liệu mock
để đánh dấu hoàn tất chức năng.
